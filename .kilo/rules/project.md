# Общие правила проекта

## Проверка компиляции
- Это Unity-проект (Unity 6 + DOTS). Стандартная .NET-компиляция не работает: `dotnet build` / `dotnet msbuild` по Unity-сгенерированным `.csproj` падает с CS0006 — не находятся метаданные зависимых сборок из `Temp/Bin/Debug/...`.
- Проект не собирается средствами .NET CLI — не запускать сборку `.csproj` для проверки кода.
- Компиляцию выполняет только редактор Unity (при перезагрузке домена). Проверка изменений в C# — ревью кода, финальная компиляция в редакторе Unity.
